== Root Cause Analysis ==
Problem: base_phi4mini GSM8K score dropped from 85.1% (.back) to 75-78% (sglang)
Root cause: sglang 0.4.6.post1 (PyPI version) contains post5 code that has a bug
in handling Phi-4-mini's LongRoPE (partial_rotary_factor=0.75). This causes the
base model to enter repetition loops (130-182 out of 1319 samples), dramatically
reducing the score. SFT models are less affected because they learned to stop
generating at "####" markers.

Solution: Use vLLM 0.8.5.post1 as the inference backend instead of sglang.
vLLM correctly handles Phi-4-mini's LongRoPE and does not produce repetition loops.
